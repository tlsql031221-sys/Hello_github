WEEK'S CAPSTONE PROJECT

Q - ROUND

현장 참여형 실시간 퀴즈 플랫폼 (서버 중심 상태 통합 관리)
누적 조회수 0

프로젝트 개요

Q - ROUND는 행사·수업·동아리에서 여러 사람이 휴대폰으로 동시에 참여할 수 있는 실시간 퀴즈 웹 서비스입니다. 진행자는 퀴즈를 만들고 방을 운영하며, 참가자는 QR 코드 및 방 코드 입력으로 쉽게 입장할 수 있습니다. 서버가 문제 진행, 답변 유효성, 점수 계산 및 실시간 순위를 통합 관리하는 것을 핵심으로 합니다.

사용 기술

Front-end: React, Vite | Back-end: Node.js, Express, Socket.IO
Database & Auth: Supabase (PostgreSQL, Supabase Auth)
Deployment & Infra: Vercel, Render / Nginx, Docker, Docker Compose

팀 소개 및 역할

Q - ROUND 개발팀

  • 이선호 (백엔드·DB): API 및 Socket.IO 서버 개발, 인증, 방 상태 및 채점 로직 구현, DB 제약조건 설정
  • 원진석 (프론트엔드): React 기반 UI/UX 구현, 실시간 소켓 화면 동기화 및 참가자 화면 구성
  • 공동 작업: 통합 테스트, 동시접속/재접속 예외 처리 시험, 시연 및 문서 작성

주요 기능 및 차별점

  • 서버 기반 정밀 판정: 클라이언트 조작 방지 (답변 검증, 중복 제출 차단, 제한시간 검증)
  • 실시간 동기화 & 버저 순서 판정: Socket.IO를 통한 동일 문제 진행, OX/객관식/버저형 문제 처리
  • 상태 복구 기능: 새로고침 및 네트워크 일시 끊김 시 게임 진행 상태 복구
  • 데이터 영속성: PostgreSQL DB 내 참가자 답변, 점수, 게임 결과 저장 및 조회
